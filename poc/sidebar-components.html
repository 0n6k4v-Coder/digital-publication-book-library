Sidebar components / PoC

A focused admin shell.

This page is intentionally content-heavy so the mobile floating capsule can be tested while scrolling. Scroll down to hide the bar, then scroll up to reveal it again.

01 / Desktop

Floating light sidebar with a compact workspace hierarchy.

The parent shell controls the six-pixel outer spacing and the six-pixel gap between sidebar and content. The sidebar does not define its own outer space.

02 / Mobile

A 64px capsule stays out of the way while reading.

Scrolling downward hides the floating top bar. Scrolling upward reveals it. Reaching the top always brings it back.

03 / Drawer

Navigation slides in from the left without compressing the page.

Open the mobile menu to test the preserved slide-in drawer, overlay, close interaction, navigation links, and distinct sign-out action.

04 / Scroll test

Keep scrolling for a few sections to validate the behavior.

Small scroll deltas are ignored to reduce jitter. The menu remains visible whenever the drawer is open.

05 / Interaction

Sign out stays visually separate from everyday navigation.

The same confirmation dialog is available from both desktop and mobile navigation so the interaction remains consistent.

06 / End

Scroll back up to bring the capsule home.

At the top of the page, the mobile capsule is always visible, regardless of the previous scroll direction.
